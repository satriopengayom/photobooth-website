### 2. PhotoSessionContext ✓
**State Structure:**
```javascript
{
  settings: {
    photoCount: 3 | 4,
    countdown: 3 | 5 | 10,
    mode: 'manual' | 'gesture',
    method: 'per-foto' | 'per-sesi',
    gesture: 'peace' | 'palm'
  },
  photos: [
    { slot: 0, blob: null, timestamp: null },
    { slot: 1, blob: null, timestamp: null },
    ...
  ],
  retakeSlot: null | number,
  sessionStarted: boolean
}
```

**Methods Implemented:**
- `startSession(settings)` - Initialize dengan fixed-length array
- `updateSettings(partial)` - Update non-locked settings
- `addPhoto(slotIndex, blob)` - Add foto ke slot specific
- `getPhoto(slotIndex)` - Get foto dari slot
- `getAllPhotos()` - Get semua foto
- `isSessionComplete()` - Check semua slot terisi
- `getNextEmptySlot()` - Get index slot kosong
- `setRetakeSlot(index)` - Set retake mode
- `clearRetake()` - Clear retake flag
- `resetSession()` - Reset all state
